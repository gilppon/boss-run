# Poki gameplay screenshots

Put three unaltered screenshots captured from the current production ZIP in this folder:

- `poki-gameplay-01.png` — the opening gameplay/tutorial action.
- `poki-gameplay-02.png` — a clear trap or boss interaction.
- `poki-gameplay-03.png` — a distinct dodge, hit, or result moment.

PNG, JPEG, and WebP are accepted by Poki's submission form. Keep each image at or below 5 MiB and 25 megapixels. The verifier checks file size and image metadata; a person must still confirm the images show real gameplay from the exact build being submitted.

These files are portal media and stay outside the game ZIP. Do not use cover art or generated mockups in place of gameplay screenshots.

Official source: [Poki submission guide](https://developers.poki.com/guide/share).
